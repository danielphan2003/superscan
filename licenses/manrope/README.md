# Manrope

Manrope by Mikhail Sharanda and Mirko Velimirovic, bundled under the SIL Open
Font License 1.1 in [OFL.txt](OFL.txt). The variable font includes weights
200 to 800. Superscan uses 400, 500, 600 and 700 with tabular numerals.
